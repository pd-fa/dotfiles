# LazyVim Migration Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan.

**Goal:** Migrate the custom neovim config to LazyVim while preserving all custom logic (tmux session management, project commands, LSP workarounds, keymaps, and extra plugins).

**Architecture:** Replace the pdolden namespace bootstrap with a LazyVim starter. Port config into LazyVim's conventional structure (lua/config/ for options/keymaps/autocmds, lua/utils/ for utilities, lua/plugins/ for plugin specs and overrides). Enable LazyVim extras for languages and tools already in use.

**Tech Stack:** Neovim, LazyVim, lazy.nvim, blink.cmp (replaces nvim-cmp), fzf-lua, snacks.nvim, mason, nvim-lspconfig, conform.nvim, copilot.lua
